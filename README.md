# Automation Engine

A mini workflow automation engine inspired by Zapier and n8n.
This project is built for learning backend system design,
event-driven architecture, and automation logic.

## Features
- JSON-based workflows
- Time-based triggers
- Conditional execution
- Action executor
- Logging & monitoring

## Tech Stack
- Python (FastAPI)
- SQLite / PostgreSQL
- APScheduler
- REST APIs
